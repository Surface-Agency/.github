# Surface Agency

Surface Agency creates the leverage brands need to punch above their weight and do more with less.

This GitHub organization houses private client delivery systems, analytics workflows, automation tools, and reporting infrastructure built for Surface Agency work.

## What Lives Here

- Paid media pacing, alerting, and reporting workflows
- Traffic forecasting and variance intelligence
- Competitive intrusion and promotion monitoring
- Restaurant-level value, clustering, and MMM analysis
- Dashboard source-of-truth repositories and operating runbooks

Most repositories are private because they contain client-specific operational context, analytics logic, or implementation details.

## Working Style

We keep repositories documentation-first, with clear runbooks, source-system notes, QA checks, and nonconformance reports where they help future work stay traceable. Changes should preserve that habit: explain the source of truth, the grain of the data, the expected outputs, and the practical caveats.

Repositories are classified by lifecycle so contributors and coding agents can tell which projects are active, sidecar, reference-only, superseded, or ready to archive. Internal inventory and governance docs live in private organization repositories.
